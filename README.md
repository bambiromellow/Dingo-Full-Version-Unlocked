## Main Features

### Core Functionality
- **Dice Activation** — Players pull a lever to roll the dice, which then displays numbers on the screen, creating a dynamic gameplay experience.
- **Scoring Mechanism** — Every number rolled is checked against the player's Bingo card, allowing them to score out numbers and accumulate points.
- **Extra Points for Columns and Rows** — Scoring out numbers from a column or row grants additional points, enhancing competitive play.
- **Completion Bonuses** — Players earn extra points for completing lines vertically, horizontally, or diagonally, adding strategic depth to the game.
